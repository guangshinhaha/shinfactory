# Execute stage evidence

- **Work type** (`bug`, `feature`, `refactor`) is `Order.WorkType`, wire field `work_type`, set by the scheduler from the issue's label or text. Empty = the stage runs on its own skill text. Plumbed like `Tier` (orderx, state, projection, canonical checkpoint, amendment merge).
- **Playbook injection:** `playbookNote` (loop/stage_evidence.go) adds shinstack's `bug-fix.md` / `feature.md` / `refactoring.md` to the execute prompt. Looked up in `$SHINSTACK_DIR/playbooks`, then the newest `~/.claude/plugins/cache/shinstack/shinstack/<version>/playbooks`. Not installed = nothing added.
- **Evidence before accepting execute** (`checkExecuteEvidence`, called in `handleCompletion`, both landing modes, so `stage_yield` is covered): run, inside the worktree, the commands under `Before a PR:` in the **main checkout's** CLAUDE.md (the cook can edit its worktree copy; none declared = none run); for a `bug`, `checkTestFirst` needs a test-only commit before the first commit touching code; Markdown-only commits are neutral. Failure = `rejectStage`: retry with the reason while attempts remain, else `failStage` and hand to a person (same path as an agent `stage_fail`; see [[codebase/needs-shin-stop-path]]).
- **Branch commits** come from `git rev-list HEAD --not <other branches>`. `--exclude` globs are relative to the `--branches`/`--remotes` namespace (`order-42`, not `refs/heads/order-42`); the wrong form silently excludes nothing and the list comes back empty.
- Tests: `loop/stage_evidence_test.go`. Swap `shinstackRoots`, `runRepoCheck`, `branchCommits`; the evidence harness uses tier `none` so gate shape stays out of the way.
- **Checks run off the loop goroutine** (`loop/evidence_async.go`): when the main checkout declares checks, `handleCompletion` starts a goroutine and returns; `finishEvidenceChecks` (top of `drainCompletions`) fails or lands the stage on the loop goroutine. While it runs the order is in `evidence.checks`, blocked from dispatch, and `edit-item` rejects it; `advance` cancels the check. A cancelled or shut-down check gives no verdict (stage left as a crash would). No declared checks = evidence stays inline. Tests use `settleEvidence`.
